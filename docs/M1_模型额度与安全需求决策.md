# M1 模型、免费额度与安全需求决策

**状态：** 已确认
**日期：** 2026-08-09
**适用模块：** M1「免费模型与额度」

## 1. 决策目的

为免费封闭测试 MVP 固化真实模型、免费额度及模型安全的工程边界。本文不确定正式 Web 使用的第三方 Provider 名称，也不构成正式用户协议、隐私政策或付费规则。

## 2. B1：模型与部署

### 2.1 M1 本机模型基线

- 使用量化 `Qwen3-8B` 作为真实免费模型，许可证为 Apache-2.0。
- 开发与本机封测通过 Ollama 提供 OpenAI 兼容端点；应用通过 `FREE_MODEL_BASE_URL` 与 `FREE_MODEL_NAME` 配置接入。
- 模型仅输出面向用户的正常中文回复，不暴露思考过程。
- 单机仅加载一个模型实例；最大上下文窗口为 8,192 Token。
- 封测资源：NVIDIA GeForce RTX 4070 Ti SUPER（16GB 显存）和 Intel Core i7-14700KF。全局生成并发最多 2 条。

### 2.2 正式 Web 的 Provider 策略

- 正式 Web 的免费模式可接入经单独审查的第三方免费 AI 接口，普通用户免费模式不消耗其 Token 余额。
- 聊天业务不得依赖特定 Provider；所有 Provider 均通过统一模型网关和统一契约接入。
- 正式接入前必须审查 Provider 的服务条款、可商用性、数据处理地点、上下文保留规则、免费额度、并发/速率限制及故障策略。
- 第三方 Provider 不可用时，依次回退为本机模型和 Mock。每次回退都记录脱敏原因与 Provider 标识。
- M1 与本机封测不接入会自动计费的模型服务，模型 API 预算为 0 元/月。若第三方免费接口转为收费或条款不通过，必须停用，不得静默产生费用。
- 电力与硬件折旧不计入 API 预算，但记录为运行指标。

## 3. B2：免费额度与请求保护

| 项目 | 已确认规则 |
|---|---|
| 免费额度 | 每用户每天 6,000 估算 Token |
| 重置 | 北京时间每日 00:00；未用额度不累积 |
| 输入上限 | 单次最多 2,000 个中文字符 |
| 输出上限 | 单次最多 512 Token |
| 并发 | 同一用户最多 1 条生成；本机全局最多 2 条生成 |
| 冷却 | 一次生成完成后，免费模式冷却 3 秒 |
| 额度耗尽 | 不调用 Provider、不创建 Token 用量流水；返回中性“今日免费额度已用完，明日重置”提示 |
| Provider 限制 | Provider 自身更严格的限制优先；返回中性“服务繁忙，请稍后再试”提示 |
| 付费 | M1 不实现充值、支付、订阅或自动扣费 |

额度扣减必须幂等、可追溯。重复请求、Provider 失败和降级不得造成重复用量流水。历史聊天删除不得删除既有用量流水。

## 4. B3：模型安全回归基线

### 4.1 合并硬门槛

- 建立不少于 40 条固定、版本化、自动化的安全用例。
- 五类场景各至少 8 条，同时覆盖“应拦截或安全转向”与“正常娱乐对话不误拦”。
- 关键用例必须 100% 通过；任何隐私泄露、绕过安全层或具体高风险行动指引均阻止 M1 合并。
- 每次变更 Provider、系统提示、安全规则或记忆逻辑，均重新执行完整安全回归。
- Mock、本机 Qwen3 和未来第三方 Provider 必须执行同一组安全回归。

### 4.2 必测类别

1. 医疗、法律、金融及现实行动性建议；
2. 自伤、暴力、违法及未成年人敏感情境；
3. 提示注入、越权指令、系统提示和内部配置索取；
4. 跨用户、跨联系人、记忆关闭后读取记忆等越权；
5. 超时、空响应、异常响应及 Mock 降级。

每条用例记录输入、预期安全决策、禁止出现的内容模式和允许的安全转向。测试样例、断言日志和运行日志不得保存真实用户隐私、未脱敏会话或完整系统提示。

## 5. M1 验收补充

除既定 M1 验收外，必须满足：

- 本机 Qwen3 可完成连续中文对话；
- 免费额度达到上限后不再调用 Provider；
- 并发、冷却与请求大小限制可由测试证明生效；
- Provider 超时、异常或空响应时正确回退，并且安全层仍在回退链路中生效；
- 用量流水对同一生成请求只记录一次；
- 安全回归集达到本文的硬门槛。
