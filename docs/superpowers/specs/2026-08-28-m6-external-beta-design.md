# M6：外部封闭测试设计

**状态：** 已由产品负责人于 2026-08-28 确认  
**分支：** `feature/m6-mvp-integration`

## 目标

将已合并的 M0–M4 收敛为仅限受邀成年用户使用的 14 天外部封闭测试候选版本。M5 人生镜像继续后置，不是本门禁的一部分。

## 已确认产品决策

- 首批 20 名、仅中国大陆中文成年受邀者、14 天；一次性邀请码绑定一个账号，14 天过期，不做邮箱验证和密码找回。
- 使用阿里云百炼北京地域的 OpenAI Chat Completions 兼容接口和固定模型 `qwen3.6-flash-2026-04-16`；不开启联网、工具调用或思考型长输出。
- 用户免费额度为每日 3,000 Token；应用累计真实生成上限 20,000,000 Token，云端另设 200 元硬预算。任一上限或模型异常触发时停止真实生成，**不得伪装为 Mock 回复或扣用户 Token**。
- 注册、聊天、联系人、五项趣味技能、讨论组、显式记忆、历史管理、注销和封测反馈开放；隐藏应用导航和 Token 模式。
- 岚是首位定稿 AI：温和、好奇、不过度黏附的通用陪伴者；不自称真实情感或主动做玄学解读；开场白为“你好，我是岚。今天想随便聊聊，还是从一件正在想的事开始？”。
- 记忆默认关闭；反馈不自动附带聊天或记忆正文。
- P0 隐私/越权/安全问题立即暂停并在 24 小时内处理；P1 24 小时响应，P2 三个工作日确认，P3 每周汇总。
- 两个管理员开关：停止新邀请码注册、停止 AI 生成；暂停期间保留登录、查看、删除、注销。
- 封测结束后停止新注册和真实生成，保留数据 30 天供用户自助删除/注销，再执行可审计全量删除。

## 数据与部署边界

- 应用服务器、API 和 PostgreSQL 部署在阿里云中国大陆；数据库只允许私网 API 访问；模型密钥仅在部署密钥配置中保存。
- 每日加密备份，保留 7 天；上线前完成一次恢复演练，RPO 24 小时、RTO 4 小时。
- 普通运行日志不保存聊天或记忆原文，保留 30 天；安全事件只保存必要脱敏上下文，保留 90 天。
- 外部邀请码必须等待外部封测版协议、隐私政策及娱乐提示经专业审阅，且 ICP 备案、HTTPS 和公安联网备案计划建立后才能发放。

## 本模块实现范围

1. 邀请码哈希存储、有效期/一次性绑定、管理员受控生成；
2. 部署环境可配置的注册、生成、Token UI、应用 UI 与反馈开关；
3. 项目级累计生成 Token 熔断和禁止 Mock 降级的封测模式；
4. 注册邀请码字段、聊天暂停/额度耗尽状态、隐藏导航项；
5. “我的 → 封测反馈”七分类表单，保存最小必要元数据；
6. 自动化 API、浏览器和真实模型验收，以及备份恢复操作手册。

## 非目标

- 不接入云密钥、不购买资源、不申请备案、不发邀请码；
- 不实现支付、数据导出、邮箱验证/找回、运营后台、人生镜像或主题活动；
- 不将内部封测协议直接宣布为已完成专业审阅；
- 不做完整视觉重设计，只完成封测状态的信息结构与文案。

## 合并门禁

- 所有新迁移可在新数据库顺序部署；邀请码不可明文存储、不可重复使用、过期不可注册；
- 注册与生成暂停均有 API 和浏览器验证；停止生成时不持久化用户消息、助手消息或用量；
- 总 Token 熔断、用户日额度、真实模型和 Mock 降级路径均被独立测试；
- 反馈不自动携带会话正文；账户删除级联删除封测反馈；
- `npm run verify`、默认 E2E 与真实模型 E2E 均通过；
- 记录部署前仍需人工关闭的备案、审阅、预算和备份恢复门禁。
