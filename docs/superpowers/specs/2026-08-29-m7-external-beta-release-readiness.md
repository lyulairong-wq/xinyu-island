# M7：外部封测发布工程化设计

**状态：** 实施中
**分支：** `feature/m7-external-beta-release-readiness`

## 目标

把已通过 M6 代码验收的封闭测试候选版，补齐为可在中国大陆受控云环境中部署、核验、备份和恢复的工程交付物。M7 不发放邀请码、不部署真实云资源，也不把人工审核或备案声明为已完成。

## 范围

1. 在 `NODE_ENV=production` 下强制校验外部封测运行配置：HTTPS Web 来源、阿里云百炼北京 OpenAI 兼容端点、固定模型、模型密钥、3,000 日免费额度、20,000,000 项目上限，以及邀请码/成年/反馈/禁止 Mock/隐藏 Token 与应用入口等开关。
2. 提供 API、Web 的可复现容器构建和仅暴露反向代理的生产 Compose 模板；PostgreSQL 通过私网 `DATABASE_URL` 接入，绝不由模板暴露数据库端口。
3. 提供生产前检查、迁移、备份、恢复演练脚本与最小化操作文档。脚本只接受显式环境变量，拒绝开发地址、明文备份和危险恢复目标。
4. 用配置单元测试与无密钥容器/脚本静态检查证明工件可用。

## 非目标

- 不开通阿里云、百炼、域名、证书、备案、预算、告警或对象存储。
- 不将密钥、邀请码、真实聊天、备份或任何个人数据写入仓库。
- 不替代协议、隐私政策、娱乐提示的专业审阅。
- 不增加支付、公开注册、M5 人生镜像或最终视觉设计。

## 发布边界

只有在以下人工门槛已留存证据后，部署管理员才可执行实际迁移、创建邀请码或开放注册：协议/隐私/娱乐提示专业审阅；主体、ICP、HTTPS 和公安备案计划；北京地域私网数据库与模型密钥；¥200 云预算/告警；一次成功的加密备份恢复演练。

## 验收标准

- 生产环境缺失或错误的封测开关、模型配置、额度、HTTPS 来源时，`loadConfig` 明确拒绝启动。
- 容器模板不包含默认密钥、邀请码或数据库端口暴露；迁移成功后 API `/api/v1/health/ready` 才可视为就绪。
- 备份必须加密并保留最近 7 份；恢复只允许显式隔离目标，拒绝生产连接字符串。
- `npm run verify`、新增脚本测试及生产配置检查通过；文档区分“代码已准备”与“外部人工门槛未完成”。
