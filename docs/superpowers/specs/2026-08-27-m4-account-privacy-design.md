# M4 账号、隐私与数据权利设计

**状态：** 已完成需求确认，待用户审核后进入开发计划

## 目标与范围

M4 为封闭测试 MVP 提供可验证的账号数据权利闭环：用户可在“我的”中查看注册时已确认的协议与隐私内容，并可主动、立即、不可恢复地注销账号和删除全部个人级数据。

本模块不实现数据导出、撤回同意、协议重签、密码修改、多设备会话管理、举报申诉、后台审核、邮件通知、冷静期或账号恢复。

## 已确认的产品规则

1. 用户协议、隐私政策和娱乐使用提示仅在注册/登录准入时确认；后续版本变更不要求重新确认。
2. “我的 → 协议和隐私”只读展示当前内部测试版正文、版本和该账号确认时间；不提供撤回或重新确认。
3. 数据导出暂不开发，也不展示入口。
4. 注销要求当前密码、不可恢复确认勾选和最终危险操作按钮；不设冷静期。
5. 注销立即删除账户资料、登录会话、同意记录、私有 AI、会话、消息、长期记忆、技能状态、令牌账户、生成请求和个人用量记录。
6. 不保留个人级审计、用量或安全摘要；未来如有统计需求，仅可保留不可反推个人身份的聚合指标，本期不实现该统计。
7. 删除优先于在途生成；在途请求后续写回必须因账户/会话不存在而失败，不得新增消息或个人级用量。
8. 被注销的邮箱可立即重新注册，但新账号不得继承任何历史资料。
9. 成功注销后清除本地凭据、跳转登录页、显示一次简短成功提示；不发送邮件，也没有恢复入口。

## 架构

采用立即硬删除。`AuthService` 负责密码校验、撤销会话与用户根记录删除；`MeController` 只暴露当前用户的同意查询和注销端点；Web 保持为薄客户端。

```text
Web“我的”
  ├─ GET /me/consents ──> MeController ──> AuthService ──> ConsentRecord
  └─ POST /me/account-deletion
        └─ AuthService: 校验密码 → 撤销会话 → transaction 删除 User
              └─ 数据库外键级联删除所有个人级关联数据
```

不新增软删除、后台队列、导出任务、个人审计表或恢复状态。`User` 是删除事务的唯一根节点；现有 `onDelete: Cascade` 关系负责级联清理关联数据。

## API 契约

### `GET /api/v1/me/consents`

需要有效 JWT。仅返回当前用户的已确认记录及固定内部测试版文档元数据：

```json
{
  "documents": [
    {
      "type": "terms",
      "title": "用户协议（内部封闭测试版 v1.0）",
      "version": "1.0",
      "content": "当前内部测试版文档的完整正文",
      "grantedAt": "2026-08-27T00:00:00.000Z"
    }
  ]
}
```

### `POST /api/v1/me/account-deletion`

需要有效 JWT，请求体：

```json
{ "password": "当前密码", "confirmed": true }
```

- 密码错误、确认缺失或确认值不为 `true`：返回通用 400 错误。
- 会话无效或账户不存在：返回 401。
- 成功：`{ "success": true }`。
- 删除成功后，调用方必须立即移除本地令牌；接口不泄露已删除资源详情。

## Web 交互

- “我的 → 协议和隐私”：显示三个只读文档入口，展开正文、版本和确认时间。
- “我的 → 设置”：提供“注销账号”危险入口。面板内按顺序完成密码输入、不可恢复确认勾选和最终提交。
- 注销成功后清空本地认证状态并回到登录页，以一次性通知展示完成结果。
- 不展示数据导出、撤回同意、冷静期、恢复账号或邮件相关内容。
- 仅复用当前信息架构与样式；最终视觉设计不在本模块定稿。

## 安全与并发

- 所有读取与删除均由当前 JWT 的用户 ID 作为唯一授权范围。
- 密码校验失败统一返回通用提示，不泄露用户状态。
- 删除前撤销全部服务端会话；删除事务完成后，旧 JWT 不再对应有效会话或用户。
- 生成协调器在最终持久化前必须重新确认用户与会话仍存在；注销后的在途生成安全失败，不写入消息或用量。

## 验收标准

| 场景 | 预期结果 | 验证方式 |
|---|---|---|
| 查看协议 | 仅显示当前用户的三份正文、版本与确认时间 | API、组件、E2E |
| 认证拒绝 | 无效 JWT 不能读取同意或注销账号 | API |
| 注销校验 | 缺少确认或密码错误不删除任何数据 | API |
| 立即删除 | 成功后个人级关联数据均不可读取，旧令牌失效 | PostgreSQL API、E2E |
| 邮箱重用 | 同邮箱可注册新账户，且没有历史继承 | API、E2E |
| 并发边界 | 注销后在途生成不得写回消息或个人级用量 | 服务测试 |
| 回归 | 完整 `npm.cmd run verify`、数据库迁移状态和浏览器 E2E 通过 | 自动验证 |
