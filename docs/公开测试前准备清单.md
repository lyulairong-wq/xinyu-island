# 心屿公开测试前准备清单

本清单不属于当前基础架构验收；它是从封闭测试进入公开测试前的发布门槛。

## 合规与内容

- [ ] 用户协议、隐私政策、AI 娱乐提示、未成年人规则和 Token 规则完成专业审核。
- [ ] 品牌、域名、商标和第三方模型/素材许可证完成核查。
- [ ] 举报、申诉、封禁、内容下线和紧急安全事件的处理流程可执行。

## 安全与数据

- [ ] 生产密钥由专用密钥管理保存，不进入代码或日志。
- [ ] 聊天、长期记忆、草稿和 API Key 均按日志脱敏规则处理。
- [ ] 数据导出、删除、账号注销、授权撤回和备份恢复已测试。
- [ ] 管理员权限、敏感查看审批和审计记录已实施。

## 部署与运行

- [ ] 中国大陆部署区域、域名、HTTPS、环境隔离和数据库网络边界已确认。
- [ ] 备份频率、保留周期、恢复目标和恢复演练已确认。
- [ ] Web/API/数据库/模型成功率/额度/安全事件均有监控和告警。
- [ ] Provider 故障、数据库故障、额度异常和安全事件有处置预案。

## 产品与运营

- [ ] 最终 UI、官方 AI 人格和首批人生镜像内容已确认。
- [ ] 免费额度数值、重置条件、模型成本上限和降级策略已确认。
- [ ] 反馈渠道、客服响应、测试规模、暂停条件和问题分级已确认。
