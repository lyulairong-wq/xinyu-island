# M3 联系人与记忆需求决策

**状态：** 已根据产品需求基线与已确认的 M2 技能规则固化，待模块实现与验收
**日期：** 2026-08-25
**适用模块：** M3「联系人与记忆」
**分支：** `feature/m3-contacts-memory`

## 1. 目标与范围

让用户可管理仅属于自己的 AI 联系人，并以“用户 × 特定 AI 联系人”为边界，管理经用户明确保存的长期记忆。M3 补齐 M2 已有聊天入口之外的联系人和记忆管理能力，不改变已确认的聊天优先信息架构或最终视觉设计。

本模块包含：

- 官方 AI 与用户私有 AI 在“联系人”页分组展示；官方 AI 只读，私有 AI 可创建、编辑、删除。
- 私有 AI 通过基础人格设定创建或更新：名称、简介、角色描述、对话语气；不建设人格版本历史、公开分享或社区。
- 私有 AI 可从平台审核技能库选择、组合并排序，最多 3 项，必须指定 1 项主技能；不得写入自定义技能或修改技能安全边界。
- “我的 → 记忆管理”按联系人查看、显式保存和删除记忆；聊天内已有的记忆开关继续作为低打扰入口。
- 提供用户级“默认开启长期记忆”设置；默认关闭，只影响新建单聊或未设置覆盖的会话，不反向修改既有会话。
- 删除私有 AI 前明确提示影响范围：删除其联系人配置、关联会话与该联系人的长期记忆；不影响其他联系人、其他记忆和历史用量流水。

## 2. 明确不包含

- 官方 AI 的人格、技能、安全规则、版本或下线运营管理。
- 用户 AI 的版本历史、公开分享、搜索、复制、转让或复杂关系成长机制。
- 群聊成员的动态编辑和讨论组长期记忆。
- 自动提取、自动保存或跨联系人共享长期记忆。
- 正式 UI/视觉定稿、头像素材生产、最终角色文案和支付功能。

## 3. 数据与权限规则

| 对象 | 规则 |
|---|---|
| 官方联系人 | 平台只读；可发起聊天和读取平台审核技能，不可编辑、删除或改写技能。 |
| 私有联系人 | 仅创建者可读取、更新和删除；所有查询和写入均以 `userId` 作为归属条件。 |
| 技能 | 仅接受审核技能目录中的代码；1–3 项，主技能必须属于所选集合；保持用户所选顺序。 |
| 长期记忆 | 仅按 `userId + contactId` 查询和注入；默认关闭；只保存用户明确操作提交的非敏感事实。 |
| 删除联系人 | 在同一受控操作中清理该私有联系人的会话、消息、成员关联和长期记忆；不删除其他联系人的数据及用量流水。 |
| 默认记忆设置 | 仅当前用户可更改；默认值只在创建新单聊时读取，既有会话的显式值不变。 |

所有联系人、记忆和删除入口复用统一安全层。不得接受身份证、精确住址、联系方式、医疗/心理、法律、财务、政治、宗教、性取向或现实预测结论作为可保存长期记忆。

## 4. API 与实现边界

- 私有联系人新增更新接口；更新时校验所有权与技能目录约束。
- 提供读取和更新“默认长期记忆”设置的用户级接口。
- 私有联系人删除使用事务，先校验归属，再删除限定范围内关联数据；失败不得留下半删除状态。
- 记忆接口继续只暴露所属用户、所属联系人的必要字段；不得因联系人删除而泄漏删除前内容。
- Web 的联系人编辑器复用既有审核技能目录和前端共享类型，不重复维护一份技能定义。

## 5. 验收用例

| 场景 | 预期结果 | 验证方式 |
|---|---|---|
| 创建私有 AI | 可保存基础设定、1–3 个审核技能及主技能，并在联系人列表中显示 | API、组件、E2E |
| 编辑私有 AI | 创建者可更新基础设定和技能顺序；官方 AI 更新被拒绝 | API、组件、E2E |
| 联系人权限 | 用户不能读取、更新或删除另一用户的私有联系人与记忆 | API 单元测试 |
| 默认记忆 | 默认关闭；开启后仅影响新单聊，既有会话值不被改写 | API、E2E |
| 记忆隔离 | A 联系人保存的记忆不出现在 B 联系人或其他用户下 | API、E2E |
| 敏感记忆 | 自动保存不存在；显式提交高敏感内容被拒绝或安全提示，不写入数据库 | API、安全测试 |
| 删除私有 AI | 二次确认后只清理该 AI 的联系人、会话、消息和记忆；其他数据及用量流水保留 | API、E2E |
| 异常处理 | 删除或更新失败显示中性提示，不产生部分可见状态 | API、组件 |

## 6. 合并门槛与已知限制

- 新增 migration 可在空数据库顺序执行，并通过当前 PostgreSQL 迁移状态检查。
- 本模块测试、相关浏览器 E2E、`npm.cmd run verify` 全部通过。
- 记录真实 PostgreSQL 验证结果、已知限制与对 M2 的回归影响。
- 不因本模块引入新的最终视觉风格、自动记忆或未确认的官方角色内容。

当前已知限制：用户 AI 人格版本历史、关系成长和官方 AI 运营配置仍属于后续模块，不作为 M3 完成条件。
