# M2 浏览器端到端验收记录

## 执行方式

2026-08-24 在 M2 隔离工作树执行：

```powershell
npm.cmd run test:e2e
```

结果：通过，4/4 条 Playwright Chromium 端到端用例通过。

该脚本会创建独立的临时 PostgreSQL 容器，应用全部数据库迁移，并在隔离端口启动 API（4100）和 Web（3100）。结束后自动停止所启动的进程并删除该临时容器；不会使用开发数据库或日常的 3000/4000 端口。

## 自动验收范围

- 注册时同意三项协议后创建账号；与官方 AI 建立单聊、发送中文消息、获得 Mock 回复并验证免费模式。
- 从技能菜单进入 MBTI 轻量流程；验证娱乐提示位于输入卡片内，不遮挡输入或再次打开技能入口；验证结果卡固定包含娱乐免责声明。
- 创建两位 AI 讨论组；验证成员依次追加回复；验证群聊技能必须显式选择具备该技能的目标成员。
- 在“我的 → 记忆管理”中新增并删除按 AI 联系人隔离的长期记忆。

## 可追溯性与隔离

测试使用临时 Playwright 浏览器上下文和本机 Chrome 可执行文件，不读取用户浏览器的配置、Cookie 或登录态。失败时将保留 trace、截图、录像及 HTML 报告，供定位问题使用。

## 尚需人工验收的范围

本轮自动化覆盖关键业务路径，但不替代视觉与体验判断。M2 合并前仍应补充：窄屏布局、其余四项技能的交互观感，以及会话归档/删除确认的人工验收。
