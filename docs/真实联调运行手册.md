# 心屿真实联调运行手册

## 环境要求

- Node.js 22+
- Docker Desktop（用于 PostgreSQL 16）
- 可选：本地 OpenAI 兼容模型服务

## 启动数据库

在项目根目录执行：

```bash
docker compose up -d postgres
```

## 初始化环境

复制 `.env.example` 为 `.env`，确认 `DATABASE_URL` 指向本地 PostgreSQL，并设置不少于 32 位的本地 `JWT_SECRET`。

## 执行迁移

```bash
npm run db:generate
npm run db:migrate
```

## 启动服务

```bash
npm run dev
```

API 默认运行在 `http://localhost:4000`，Web 默认运行在 `http://localhost:3000`。

## 验收顺序

1. 注册并确认年龄分级、用户协议、隐私政策和娱乐提示。
2. 登录后查看官方联系人并创建一个私有联系人。
3. 创建对话，切换对话级记忆开关，发送普通消息。
4. 在“我的”中查看联系人记忆与免费额度。
5. 验证高风险内容得到安全拦截提示。
6. 验证服务重启后对话、联系人、记忆和配额记录仍存在。

## 自动化联调

默认端到端测试会启动独立的临时 PostgreSQL，并**强制不配置模型**，用来验证模型不可用时会明确降级为 Mock 回复：

```bash
npm run test:e2e
```

如本机已运行 Ollama 且已安装 `qwen3:8b`，可执行真实免费模型联调。该命令同样只使用临时数据库和临时测试账号；它会要求聊天接口返回 `local` 提供方，若静默降级为 Mock 则测试失败：

```powershell
$env:FREE_MODEL_BASE_URL='http://127.0.0.1:11434/v1'
$env:FREE_MODEL_NAME='qwen3:8b'
$env:FREE_MODEL_TIMEOUT_MS='90000'
npm run test:e2e:real-model
```

真实模型的单次生成可能比 Mock 更慢；该专用测试允许最多 120 秒，但模型服务自身仍按 `FREE_MODEL_TIMEOUT_MS` 超时。不要把此命令用于生产数据库或真实用户账号。
