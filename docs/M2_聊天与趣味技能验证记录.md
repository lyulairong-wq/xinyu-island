# M2 聊天与趣味技能验证记录

## 验收清单

- [ ] 未登录请求与跨用户资源访问均被服务端拒绝。
- [ ] 官方联系人不可被编辑或删除；私有联系人仅可由本人管理，并受最多 3 个已审核技能及 1 个主技能限制。
- [ ] 平台仅提供塔罗、MBTI、星座、紫微斗数、梅花易数五项技能。
- [ ] 高风险话题在生成、扣减额度或持久化前被安全策略拒绝。
- [ ] 群聊技能必须由用户显式选择具备该技能的成员，并将该成员作为目标。
- [ ] 聊天支持引用、复制、重新生成与继续；历史不会被静默覆盖；草稿按会话隔离。
- [ ] 桌面双栏与移动单栏导航均可用；会话归档/删除需明确确认。
- [ ] 技能卡片固定展示“趣味解读，仅供娱乐参考”，且不显示原始出生信息等输入。
- [ ] 技能事实仅在用户显式选择并输入内容后保存至对应 AI 联系人；可删除。
- [ ] 免费/Token 模式延续开发模拟额度语义，不含充值、支付或真实扣费路径。
- [ ] 全量自动化、生产构建和全新数据库迁移均通过。
