# 心屿最小可用版本（MVP）验收标准

状态：首个开发目标节点

## 1. MVP 定义

本 MVP 是面向中国大陆中文用户的免费封闭测试 Web 版本。目标是验证“娱乐陪伴聊天”这一核心体验是否可用、可理解且可控，不是公开商业版。

MVP 必须以真实可用的免费开源模型为主、Mock 为故障保底；不接受只依赖固定 Mock 回复作为验收通过。真实 Token 付费、充值、订阅、公开注册、语音/视频和公开社区不属于本节点范围。

## 2. 纳入范围

### 2.1 用户核心闭环

受邀测试用户必须能够完成：

```text
注册并同意协议与娱乐提示
  → 登录进入聊天首页
  → 选择至少一名已确认的官方 AI 联系人
  → 使用免费模式完成连续对话
  → 查看历史会话并继续聊天
  → 管理本次对话的长期记忆开关
  → 查看、删除自己保存的记忆或聊天内容
```

### 2.2 功能验收

| 能力 | 通过条件 |
|---|---|
| 注册与登录 | 邮箱密码注册、登录、退出、会话失效处理正常；注册必须分别记录用户协议、隐私政策和娱乐用途提示同意。 |
| 聊天首页 | 采用已确认的聊天优先信息架构；桌面与手机浏览器均能完成核心闭环。 |
| 官方 AI | 至少一名人格、内容边界和开场方式已确认的官方 AI 可用；不得使用仅供开发的占位人格作为封闭测试内容。 |
| 免费对话 | 默认免费模式；真实开源模型能完成正常中文连续对话；Provider 失败时自动降级为 Mock，且不向用户伪装为真实模型。 |
| 娱乐边界 | 首次使用前或首次聊天前出现简洁明确的娱乐用途提示；正常对话中不反复打断沉浸体验。 |
| 安全拦截 | 医疗、法律、财务、危险行为、自伤他伤和未成年人高风险内容不提供具体行动建议；返回统一、克制的边界回应。 |
| 会话与消息 | 用户可创建、续聊、重命名、归档、恢复、删除自己的会话；支持引用与删除消息；删除后不再用于后续对话上下文。 |
| 联系人与记忆 | 联系人间长期记忆完全隔离；默认关闭；用户可在会话内开启或关闭，并可查看和删除自己保存的记忆。 |
| 免费额度 | 有明确的免费资源限额与重置条件；达到限额时不继续调用模型，并给出清晰的非付费提示。 |
| 隐私与删除 | 用户可删除自己的会话和记忆；删除范围、不可恢复性及 Token/用量流水的独立性有明确说明。 |

## 3. 不属于 MVP 通过条件

- 真实 Token 充值、支付、订阅、退款或发票。
- 用户 AI 的完整人格版本管理、分享或公开社区。
- 多 AI 讨论组的最终交互体验。
- 人生镜像与主题活动，包括入口、剧情库与运营体系；基础功能完善后另行立项。
- 语音、视频、图片生成、多语言和移动原生 App。
- 公开注册、应用商店发布或大规模并发承诺。

现有已实现的群聊、私有联系人和 Token 数据底座可以保留，但不因其存在而自动计入 MVP 验收范围。

## 4. 质量与安全门槛

| 项目 | 通过条件 |
|---|---|
| 自动验证 | `npm.cmd run verify` 全部通过；数据库迁移状态为 up to date。 |
| 真实联调 | 使用默认 PostgreSQL 和真实免费模型端点，完成注册、聊天、历史、记忆开关、删除和额度限制的 API 与浏览器流程验证。 |
| 数据隔离 | 至少覆盖会话、消息、记忆、联系人和用量记录的跨用户拒绝访问测试。 |
| 安全测试 | 覆盖高风险咨询、未成年人敏感内容、提示注入和记忆越权访问的测试用例。 |
| 降级测试 | 人为使免费 Provider 不可用时，Mock 降级、错误记录和用户提示符合规则。 |
| 浏览器支持 | 最新 Chrome、Edge 和手机 Chrome/Safari 至少各完成一次核心闭环人工验证。 |
| 性能基线 | 在封闭测试目标并发下，正常免费回复有可记录的成功率、耗时和降级比例；具体数值在模型部署方案确定时写入测试计划。 |
| 可恢复性 | 开发数据库备份与恢复流程至少演练一次；迁移可在新建数据库顺序执行。 |

## 5. MVP 发布前置条件

以下项目未完成时，只能进行内部开发或受控演示，不能开放邀请测试：

1. 最终聊天 UI 与至少一名官方 AI 人格内容已单独确认。
2. 免费模型部署、资源上限、降级策略和可观测指标已确定。
3. 封闭测试使用的用户协议、隐私政策和娱乐用途提示完成专业审核或明确为仅内部测试版本。
4. 用户数据删除、备份恢复、日志脱敏和安全事件处理流程已演练。
5. 已指定测试范围、反馈渠道、问题分级与暂停测试条件。

## 6. 验收结论

只有所有“纳入范围”和“质量与安全门槛”项通过，且 MVP 发布前置条件满足，才能标记为 `MVP-ready-for-closed-beta`。

该标记不等于公开上线许可。公开发布前仍需完成正式法律审核、生产部署评审、容量评估、监控告警和运营处置准备。
