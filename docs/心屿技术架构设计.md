# 心屿（Island）技术架构设计

版本：0.1  
状态：基于需求基线的开发前设计  
目标：支持中国大陆用户的线上响应式 Web 产品

## 1. 架构目标

- 用户通过手机和电脑浏览器访问，不安装桌面软件或模型。
- 免费模式和 Token 模式可替换 Provider，业务层不依赖具体模型厂商。
- 聊天、记忆、额度和安全能力可追溯、可测试、可回滚。
- 单聊和多 AI 讨论组共享统一会话模型。
- 人生镜像副本使用结构化状态和分支，而不是只保存生成文本。
- 用户数据、AI 联系人记忆和额度流水严格隔离。
- 生产环境优先部署在中国大陆区域，默认不跨境处理用户数据。

## 2. 总体拓扑

```text
Browser
  │ HTTPS / SSE
  ▼
Web App（Next.js）
  │ REST / SSE
  ▼
API（NestJS）
  ├── Auth & Authorization
  ├── Contact Domain
  ├── Conversation Domain
  ├── Group Orchestrator
  ├── Memory Domain
  ├── Scenario Domain
  ├── Quota & Usage Ledger
  ├── Safety Gateway
  ├── Admin Domain
  └── Audit & Observability
  │
  ├── PostgreSQL（业务权威数据）
  ├── Object Storage（头像和受控素材，后置）
  ├── Free Provider Chain
  │     ├── Self-hosted Open-source Model
  │     └── Mock Provider
  └── Token Provider（远程或平台配置 Provider）
```

## 3. 工程边界

```text
apps/web        用户 Web
apps/api        业务 API
apps/admin      后台管理，可先作为 API 受保护路由
packages/contracts 共享 DTO、枚举、错误码
packages/config 配置解析和环境校验
packages/ai     Provider 接口、路由和计量适配
packages/safety 安全分类、策略和提示模板
```

旧项目代码不参与正式实现。正式仓库以新的模块和数据库迁移为唯一实现来源。

## 4. API 分层

### 4.1 Controller 层

负责认证、权限、DTO 验证、请求 ID 关联、HTTP 状态和错误码映射；不负责业务决策、Prompt 组装或额度扣减。

### 4.2 Application 层

负责用例编排，例如：

- RegisterUser
- StartConversation
- SendMessage
- CreateGroupConversation
- ToggleMemory
- GenerateScenarioTurn
- ConsumeQuota
- ReportMessage

### 4.3 Domain 层

负责联系人版本、会话参与者、消息状态、记忆作用域、额度扣减、安全策略和人生模拟分支一致性。

### 4.4 Infrastructure 层

负责 Prisma/PostgreSQL、JWT 和密码哈希、Provider HTTP/SSE 客户端、模型服务适配、日志、指标和审计写入。

## 5. AI Provider 架构

统一接口建议包含：

```ts
interface AiProvider {
  generate(request: GenerationRequest): AsyncIterable<GenerationEvent>;
  estimateUsage(request: GenerationRequest): UsageEstimate;
  healthCheck(): Promise<ProviderHealth>;
}
```

### 5.1 免费模式

```text
FreeModeRouter
  ├─ SelfHostedOpenSourceProvider
  └─ MockProvider
```

- 优先调用自托管开源模型。
- 模型不可用、超时或资源不足时转 Mock。
- 对用户只显示“免费模式”。
- 后台记录实际 Provider 和降级原因。
- 免费模式不扣用户 Token，但有独立资源限流。

### 5.2 Token 模式

```text
TokenModeRouter
  └─ ConfiguredRemoteProvider
```

- 使用平台后台配置的 Provider、模型和密钥。
- 输入和输出实际 Token 写入 Usage Ledger。
- 额度扣减与生成请求绑定幂等键。
- 无有效回复时按规则回滚或进入异常消耗处理。

## 6. 消息生成流程

```text
接收请求
  → 验证会话和参与者权限
  → 检查请求幂等键
  → 输入安全检查
  → 读取允许的角色配置和记忆
  → 组装上下文
  → 选择免费/Token Provider
  → 生成流式事件
  → 输出安全检查
  → 持久化消息和使用量
  → 更新会话状态
```

Provider 失败不能伪装成成功回复。免费模式允许内部降级为 Mock；Token 模式失败时必须明确返回状态，并允许用户切回免费模式。

## 7. 多 AI 讨论组

采用编排器而不是让多个请求并行写入同一会话：

```text
GroupOrchestrator
  ├─ resolveParticipants()
  ├─ resolveMention()
  ├─ chooseTurnOrder()
  ├─ buildParticipantContext()
  ├─ generateOneTurn()
  └─ persistTurn()
```

每一轮只允许一个 AI 写入回复。`@角色名` 可以缩小参与者范围。群聊上下文共享，但长期记忆按联系人隔离。

## 8. 记忆架构

记忆作用域：

```text
User × Contact      联系人私有长期记忆
Group × Conversation 讨论组临时记忆
User Shared Memory  首版不启用
```

记忆写入流程：消息完成 → 判断记忆模式 → 提取候选非敏感事实 → 低打扰写入或敏感内容等待确认 → 记录来源消息和联系人。

记忆读取必须带作用域和联系人 ID，禁止使用无作用域的全局记忆查询。

## 9. 人生镜像副本架构

采用事件和快照并存：

- 事件记录用户选择和系统生成结果。
- 快照记录某个节点的可恢复状态。
- 分支从任意节点创建，不覆盖原分支。
- 生成内容和场景状态分开保存。
- 结果明确标记为虚构模拟。

核心服务：`ScenarioTemplateService`、`ScenarioRunService`、`ScenarioBranchService`、`ScenarioStateService`、`ScenarioGenerationService`。

## 10. 安全网关

所有 AI 生成入口统一经过：

```text
InputSafetyCheck
  → ContextSafetyCheck
  → ProviderGeneration
  → OutputSafetyCheck
  → AgePolicyFilter
  → PersistOrBlock
```

安全网关不能被用户自定义 AI 的人格配置覆盖。安全事件需要关联用户、联系人、会话、消息和策略版本，但普通日志不保存完整聊天正文。

## 11. 认证与权限

- 邮箱密码注册登录。
- 密码使用安全哈希存储。
- Access Token 与可撤销会话记录关联。
- 用户只能访问自己的会话、联系人、记忆和额度视图。
- 官方 AI 只允许后台发布配置。
- 用户 AI 默认私有。
- 后台使用独立管理员权限和审计。

## 12. 可追溯与可恢复

- 每次业务变更关联 request ID、actor ID、domain object ID 和版本。
- AI 生成请求使用幂等键。
- Token 使用记录不可通过删除聊天回滚。
- 数据库结构只能通过 Prisma migration 变更。
- 内容配置采用版本发布，不直接覆盖线上版本。
- 每个里程碑创建 Git tag 和可部署构建产物。
- 生产数据加密备份并定期验证恢复。

## 13. 线上部署原则

- 开发、测试、预发布和生产环境隔离。
- AI 密钥仅保存在服务端密钥配置中。
- 数据库为业务权威数据源。
- Provider、模型、额度和安全策略通过后台或环境配置管理。
- 生产日志不记录 API Key、完整聊天和长期记忆原文。
- 监控可用性、生成成功率、降级比例、额度异常和安全事件。

## 14. 首阶段实现边界

先实现：

1. Web/API workspace
2. PostgreSQL 和 Prisma 基础
3. 配置校验和健康检查
4. Auth 基础模型
5. Contact、Conversation、Message 最小模型
6. Mock Provider 和统一生成接口
7. CI、测试和构建门禁

暂不实现：真实支付、多语言、语音/视频、图片生成、复杂向量记忆检索、公开社区和用户 AI 分享。
