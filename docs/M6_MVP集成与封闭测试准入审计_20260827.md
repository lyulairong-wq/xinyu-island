# M6：MVP 集成与封闭测试准入审计

> 日期：2026-08-27  
> 分支：`feature/m6-mvp-integration`  
> 状态：已确认以“邀请外部用户的封闭测试”为目标；等待准入与运营决策确认

## 1. 本模块目的与范围

M6 不新增“人生镜像”内容，也不替代后续的正式视觉设计、官方角色内容定稿或生产部署。它的目的，是把已经独立验收的基础模块收敛为一个可邀请外部用户参与封闭测试的 MVP 候选版本。

依照已确认的产品决策，人生镜像（M5）后置，**不作为本次 MVP 通过条件**。

本模块当前纳入：

- M0 基础工程、认证、协议与数据基础；
- M1 免费模型/Mock 降级、配额与用量记录；
- M2 聊天、联系人、讨论组、记忆、技能及安全边界；
- M3 应用与“我的”基础入口；
- M4 账号、协议/隐私展示、注销及删除闭环；
- 跨模块真实数据链路、回归测试及封闭测试准入判断。

本模块不纳入：人生镜像（M5）、真实支付/充值、公开注册投放、最终 UI 视觉稿、正式生产基础设施建设及数据导出功能。

## 3. MVP 准入项对照

| 准入项 | 判断 | 当前结论 |
| --- | --- | --- |
| 核心闭环可运行 | 基本具备 | 已有注册到聊天、记忆、删除的模块级证据；仍需一次跨模块统一回归。 |
| 真实免费模型 | 内部验收已具备 | 本机 Qwen/Ollama 已通过独立真实模型 E2E：接口返回 `local`，不得静默降级为 Mock；默认 E2E 仍刻意关闭模型配置并验证 Mock 降级。对外部署方案仍未确认。 |
| 最终聊天 UI | 未满足正式封测条件 | 现有 UI 是可用的结构实现；项目已明确最终视觉设计须另行确认。 |
| 至少一位官方 AI 的最终人设、边界、开场 | 未满足正式封测条件 | 技术配置及首发技能已存在；最终角色内容仍保留后续细化空间。 |
| 协议/隐私/娱乐提示 | 技术实现具备 | 已在注册时确认并在“我的”中可查看；正式文本是否完成业务/专业审阅未在仓库中确认。 |
| 删除、备份、日志脱敏与安全事件演练 | 未满足 | 账号删除代码已具备，但备份恢复演练、日志处置与事件响应流程尚未形成可执行的封测记录。 |
| 测试运营规则 | 未满足 | 受邀用户范围、反馈入口、暂停/下线规则尚未确认。 |
| 受邀用户准入 | 未满足 | 当前注册入口对任何满足年龄与协议确认条件的用户开放；尚无邀请码、白名单或其他封测准入控制。 |
| 浏览器兼容与性能基线 | 部分具备 | 已有 Chrome 自动化与人工体验记录；Edge 和移动浏览器的系统性验收、并发/性能基线尚未完成。 |

## 4. 当前结论

当前版本仍可称为 **“内部集成验收候选”**：可以在开发者控制的本机环境中，使用真实本地模型或 Mock 降级完成完整功能验证。

它尚不应直接被标记为 **“可邀请外部封闭测试”**。阻塞项不是基础功能缺失，而是下列产品、运营和基础设施决策尚未定稿：最终体验基线、对外免费模型运行方案、数据运营演练、受邀用户准入控制和测试规则。

### 本次审计新增验证

- `npm run test:e2e`：8 项通过、1 项真实模型测试按设计跳过，确认默认回归的 Mock 降级路径；
- `npm run test:e2e:real-model`：使用本机 `http://127.0.0.1:11434/v1` 与 `qwen3:8b` 通过，确认单聊回复的 `provider=local`、`degraded=true`，并在界面显示“当前使用免费开源模型回复，仅供娱乐参考”。

## 5. M6 可直接开展的工作

以下工作不会扩大产品范围，可在本分支继续完成：

1. 汇总 M0–M4 的跨模块回归场景，补齐统一自动化验证；
2. 增加“真实模型联调”可重复执行的前置检查、运行说明和验收记录模板；
3. 检查注销、记忆隔离、配额、技能安全回退等跨模块数据边界；
4. 建立封闭测试准入清单、受邀用户准入与缺陷分级记录，不生成实际邀请或对外发布；
5. 输出兼容性、性能与可观测性需要补测的明确清单。

## 6. 需要产品负责人确认的决策

下列事项会影响对外体验、外部成本、数据责任或产品定位，不能自行假设：

1. 外部封测的免费模型策略：选定第三方免费接口/部署方案；
2. 受邀用户的准入方式：邀请码、白名单或其他受控方式；
3. 是否在最终聊天 UI 与至少一位官方 AI 的人设、开场白定稿前启动外部邀请；
4. 封测人数/范围、反馈收集方式，以及严重问题时的暂停测试规则；
5. 备份、恢复、日志脱敏和安全事件处理的责任人与演练方式。

## 7. M6 合并门禁（草案）

M6 可合并至主干的最低条件：

- 新增的统一回归与现有全量测试均通过；
- 已记录真实模型联调与 Mock 降级两种路径的结果；
- 已明确 M5 不在本 MVP 门禁中；
- 准入清单对每一项标注“已通过、延期、需决策”及证据；
- 未将未确认的 UI、角色文案、第三方模型、运营政策伪装为已完成事项。

外部封闭测试的准入条件，则必须在此基础上逐项关闭第 3 节中标记为“未满足”的项目。
